# 患者随访工作台

离线单页应用：载入销售底表（xlsx），自动汇总患者购药与存续状态，支持随访备注。

## 使用方式

1. 打开本页（就是仓库的 Pages 地址）
2. 首次使用：把完整的销售底表 xlsx 拖进页面（默认"全量替换"模式）
3. 以后更新：点左上角"导入新数据"，选"增量追加"模式，拖入当月新数据即可，自动去重
4. 已填写的诊断、备注保存在本机浏览器，不会上传到任何服务器
5. 建议定期点"导出备份(含数据池)"保存 JSON 文件，换电脑时用"导入备份"恢复

## 说明

- 数据不出本机：所有计算与存储都在浏览器本地完成
- 患者唯一键 = 开票抬头 + 会员电话
- 存续状态口径：理论下次购药 = 末次购药 + 末次购药所在自然月数量 × 30 天；早于当天为"脱落"，7 天内到期为"断药预警"，其余为"在治"
